# Lectura

El texto bíblico con licencia no se guarda en el repositorio. La lectura pide el capítulo a `capituloDePrueba`. Si `AUDITE_TEXTO_URL` está vacío, se muestra un fixture ficticio y marcado. Si la variable tiene una dirección, la pantalla dice que el almacén privado no está conectado y no descarga nada.

Los tiempos por versículo salen del manifiesto (`tiemposVersiculo`) cuando existan. Si no están, la lectura sincronizada lo dice y no inventa un resalte.
